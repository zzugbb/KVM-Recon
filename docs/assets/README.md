# 项目介绍视频

`kvm-recon-promo-v3-1080p.mp4` 是约 96 秒的项目概念介绍。文件名中的 `v3` 是视频素材修订号，不是应用版本。主 README 的 GitHub 附件是 720p 播放版，本目录保存 1080p 原片；仓库不含剪辑工程、配音稿或 720p 源文件。

## 与 0.3.1 的关系

- 架构、手工登录、记录证据、自动收尾后手动导出、Capture Pack 2.0 和合成案例仍可用于介绍当前产品。
- 约 5–11 秒的 `kvm-recon capture ...` 是概念动画，当前产品使用桌面界面，不提供该命令行采集入口。
- 约 53–57 秒的依赖版本属于制作时的快照，当前依赖以根目录 `package.json` 和锁文件为准。
- 约 29–35 秒的稳定等待说明是概览。0.3.1 修复持续绘帧反复重置等待的问题，具体收尾条件见[现场指南](../field-guide.md)。片中节奏不代表实际采集耗时，也不证明某台设备兼容。

2026-11-03 已对本地原片进行解码和抽帧文字核对。本次保留视频作为历史概念展示，并在中英文 README 加入范围说明；没有重制视频或替换远端 720p 附件。以后修改画面时，应同步检查两种分辨率与 README 的引用。实际验证范围见[项目状态](../status.md)。
